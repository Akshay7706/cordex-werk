# Cordex Werk — SaaS-Elite Digital Agency

**Cordex Werk** is a high-fidelity, production-grade digital experience engineered for startups and SaaS enterprises. This platform combines cinematic 3D interaction (React Three Fiber) with a high-performance conversion engine and a dedicated intelligence viewer.

## 🚀 Key Systems

### 1. SaaS-Elite Conversion Engine
A centralized inquiry and lead-capture system designed to minimize friction and maximize conversion rates.
- **Global Inquiry Gateway**: Context-aware modal for project launches and strategy calls.
- **Dynamic Pricing**: Tier-based mission initialization linked to the global inquiry state.
- **Advanced Services Side-Panels**: Interactive, content-rich panels for deep-dive service discovery.

### 2. Codex Intelligence Viewer
An immersive, distraction-free reading experience for editorial insights.
- **Glassmorphic Modal**: Cinematic typography and content-focused layout.
- **Lead Bridge**: Integrated CTAs within the reader to transform intelligence into consultation.
- **Authoritative Metrics**: Displays read time, category, and strategic takeaways.

### 3. Production Architecture
- **Tech Stack**: React 19, Vite 8, Framer Motion, Tailwind CSS, Lucide Icons.
- **Core Engine**: React Three Fiber (3D Abstract Scenes) + Starfield Background.
- **Build Stats**: 19.63s build time, optimized for sub-second first-input delay.

## 🛠️ Development & Deployment

### Commands
- `npm run dev`: Launch the interactive development server.
- `npm run build`: Generate a production-stable Rolldown bundle.
- `npm run preview`: Preview the production static site locally.
