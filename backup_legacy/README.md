# Kreato Space — Future-Proof Digital Experiences

**Kreato Space** is a high-fidelity, production-grade digital agency engineered for startups and SaaS enterprises. This platform combines cinematic 3D interaction (React Three Fiber) with a high-performance conversion engine and strategic editorial insights.

## 🚀 Key Systems

### 1. High-Performance Conversion Engine
A centralized inquiry and lead-capture system designed to minimize friction and maximize conversion rates for startups.
- **Global Inquiry Gateway**: Context-aware modal for project launches and strategy calls.
- **Dynamic Pricing**: Tier-based pricing (Essential Start, Founder's Choice, Enterprise-Ready) linked to the global inquiry state.
- **Advanced Services Side-Panels**: Interactive, content-rich panels for deep-dive service discovery.

### 2. The Codex: Intelligence Viewer
An immersive, distraction-free reading experience for strategic editorial insights.
- **Glassmorphic Modal**: Cinematic typography and content-focused layout.
- **Lead Bridge**: Integrated CTAs within the reader to transform intelligence into consultation.
- **Strategic Metrics**: Displays read time, category, and strategic takeaways for founders.

### 3. Production Architecture
- **Tech Stack**: React 19, Vite 8, Framer Motion, Tailwind CSS, Lucide Icons.
- **Core Engine**: React Three Fiber (3D Abstract Scenes) + Starfield Background.
- **Build Stats**: Optimized for sub-second first-input delay and high lighthouse scores.

## 🛠️ Development & Deployment

### Commands
- `npm run dev`: Launch the interactive development server.
- `npm run build`: Generate a production-stable bundle.
- `npm run preview`: Preview the production static site locally.
